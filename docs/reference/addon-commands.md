title: "Addon commands"
summary: "The Bobber Marker chat command, and the game settings the addon uses."
order: 3
---

| Command | Effect |
| --- | --- |
| `/bobbermarker` | Shows how far the box sits from the bobber's marker spot, in pixels. |
| `/bobbermarker y <pixels>` | Moves the box up or down. Negative numbers move it down. The default is `-40`, for the camera zoomed all the way out; the addon moves the box further down and makes it bigger as you zoom in. |

The setting is saved with your other addon settings and kept between sessions.

## Game settings the addon uses

| Setting | Set to | When |
| --- | --- | --- |
| Enable Interact Key (soft targeting) | on | Each time you start fishing |
| Nameplates for world objects | on | Each time you start fishing |
| Interact range limit | off, 60 yards | Each time you start fishing |
| Nameplate on the interact target | on | Only while you fish; then back to your setting |
