The fishing cycle

From bobber to bite

1 Find the bobber
The addon draws pink brackets around your bobber so Go Fish knows where to look.
2 Watch for the bite
Go Fish watches that small patch of water for a splash. It also listens for the bite when game sounds are on.
3 Reel it in
When a fish bites, Go Fish reels it in, pauses and casts again.

The Windows app

Inside Go Fish

Three steps · About five minutes

Ready for your first cast?

  1. 1

    Open Go Fish

    Download Go Fish and start it while the game is open.

  2. 2

    Install the addon

    Confirm your cast key, click Install addon, then type /reload in the game.

  3. 3

    Start fishing

    Stand at the water, click Start fishing and switch to the game. Click Stop in Go Fish to end the run.
